# 가입신청서 내의 요금제 페이지 개선

U+유모바일 가입신청서 요금제 선택 화면 UX 개선 프로젝트의 통합 리포트입니다.

## 열람

배포 URL로 접속하면 바로 열립니다. 별도 설치나 빌드가 필요 없습니다.

```
https://<계정>.github.io/<저장소명>/
```

## 리포트 구성

| 탭 | 내용 |
|---|---|
| 01 화면설계 | 요금제 화면(S-02) 화면설계서. 영역 명세 · 상태 정의 · 인터랙션 · 반응형 · 접근성 · 노출/운영 규칙 · 데이터 매핑. **배포된 프로토타입 실측 기준** |
| 02 프로토타입 | 동작하는 요금제 선택 화면. 탭 전환·필터·정렬·카드 선택·비교 담기·확정까지 실제 조작 가능. 시나리오 시뮬레이터에서 검증 시퀀스를 STEP 단위로 확인 |
| 03 기능정의 | 화면 및 URL 정의 · 검증 시퀀스 · 노출 데이터 · 예외 처리 · 데이터 연동 |
| 04 요구사항 정의서 | 핵심 문제 정의(P1~P5) · 개선 원칙 · 공통 기준(Baseline) · 측정 기준 |
| 05 개선안 | 개선 배경(데이터 근거) · 프로세스 개선(AS-IS/TO-BE) · 화면 개선 · 데이터·노출 규칙 |

## 프로토타입 사용 안내

- **자유 조작** — 카드를 눌러 요금제를 선택하고 하단 `신청서 작성하기`로 확정합니다. 선택 시 스크롤 위치가 유지되는 동작, 필터·정렬의 리로드 없는 처리, 목록의 스크롤 점진 렌더를 확인할 수 있습니다.
- **비교하기** — 카드 하단 `비교 담기`로 최대 2개를 담으면 하단 시트가 열립니다. 담은 항목은 탭을 이동해도 유지됩니다.
- **시나리오 시뮬레이터** — 정상 진입 2건(케이스 A 요금제 선택 후 진행 / 케이스 B 요금제 선택 전 진행)과 예외 1건(조회·필터 결과 0건)을 실행하면 좌측 로그에 STEP별 PASS / FAIL / SKIP이 출력됩니다.
- **리로드** — 상단 또는 폰 하단 버튼으로 조작 상태를 초기 상태로 되돌립니다.
- **모바일 / PC 전환** — 상단 `모바일 394` · `PC 700` 토글로 두 레이아웃을 즉시 비교합니다. PC는 실제 서비스 실측 기준(오버레이 위 700px 풀 팝업 · 콘텐츠 644px · 헤더 84px · 요금제 카드 2열)으로 구성했습니다.

## 데이터 안내

프로토타입에 표시되는 요금제는 **샘플 데이터**입니다. 실제 관측된 요금제 8종에 검증용 케이스(프로모션가 없는 요금제, 청소년 전용, 상담사 전용, 미사용 전환 등)를 더해 구성했으며 5G 요금제는 샘플입니다. 가격·혜택은 실제 판매 조건과 다를 수 있습니다.

리포트의 정량 근거는 Microsoft Clarity 데이터(2026-06-29 ~ 07-29, 30일)를 기반으로 합니다.

## 기술 사양

- 단일 HTML 파일 (외부 리소스·CDN 의존성 없음)
- 인라인 CSS · Vanilla JavaScript
- 브라우저 저장소 미사용 — 모든 상태는 메모리에서만 관리
- 반응형 (모바일 우선 설계, 데스크톱에서는 2단 레이아웃)

## 갱신 방법

`index.html`을 교체하고 커밋하면 1~2분 내 반영됩니다. 브라우저 캐시로 이전 버전이 보이면 URL 뒤에 `?v=2` 를 붙여 확인하세요.
