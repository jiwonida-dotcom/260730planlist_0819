**① 5G 단말의 LTE 요금제 가입 (운영 중)**

> ※ 23.11.07 CMS에서 5G 단말에 'LTE 요금제 가입 가능' 기능 추가 후 CMS의 설정에 따라 요금제 선택 가능

- 단말명 : (중고)갤럭시 S22 256G
- 모델명 : `RF-SM-S901N`
- 요금제 선택 화면 및 요금제 팝업 내 "LTE, 5G" 요금제 모두 노출

**② 단말 결합 요금할인 적용 — ※ 24.06.28 기준 미사용**

- 대상 단말 : 갤럭시 A23 (`SM-A235N`), U+키즈폰 with 춘식이 (`SM-G525N-UC`), 아이폰 11 64G (`RF-A2221-64`), 아이폰 11 128G (`RF-A2221-128`)
- 대상 요금제 : LTE (2GB/120분) `LPZ0019033`
- 월 통신요금 할인 적용하여 표기 (20,900원 → 19,900원)

**③ 쿠팡요금제 노출 조건 — ※ 24.06.28 기준 미사용**

아래 조건일 경우만 "특화요금제"에 쿠팡요금제 노출

- CASE 1. 유심 보유 : `K3620` / `3630` 원칩모델코드를 선택한 경우
- CASE 2. 유심 미보유 : 배송 방법을 "쿠팡요금제 전용 유심 오늘배송/택배" 선택한 경우
- CASE 3. 쿠팡 요금제 선택하여 진입했을 경우

> 원본 표기 그대로 — CASE 1의 두 번째 코드는 `3630`으로 적혀 있습니다(`K` 누락 추정, 원본 미교정).
