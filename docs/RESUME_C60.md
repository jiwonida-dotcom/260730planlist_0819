### 구현 요점 3가지 (되돌리면 안 되는 부분)

1. **`paintCardPick()`으로 부분 갱신** — `pickCard`에서 `render(key)`를 부르면 `.alert`의 `animation:pop .28s`가 재생되어 카드를 누를 때마다 레이어가 튑니다. 선택 표시(`.ccitem` 클래스 · `aria-checked`)와 하단 금액(`.ccfoot .v`)만 바꾸고 `paintSticky(key)`를 함께 호출합니다. `data-cc` 속성으로 행을 식별합니다.
2. **`.alert button.ccitem` 스코프** — `.alert button`(0-1-1)이 CTA 그라데이션 · 흰 글자 · `padding:13px` · `min-height:48px`를 주므로 `.ccitem`(0-1-0)만으로는 미선택 카드가 보라색으로 칠해집니다. 레이어 내부 버튼은 반드시 `.alert` 를 붙여 우선순위를 맞춥니다.
3. **보더 1 → 2px 증가분만큼 padding 1px 축소** (`12.5/13.5` → `11.5/12.5`) — 선택 전후 목록 높이가 변하지 않아야 합니다(C-26과 같은 원칙). 실측 `.cclist` 높이 **368.5625px**가 4회 선택 내내 불변임을 확인했습니다.

## 2-1. ① 추가 반영 (2026-08-18 2차) — 목업으로 옮길 때 이 상태를 기준으로 삼을 것

사용자 요청으로 ① 프로토타입이 한 번 더 바뀌었습니다. **② 목업은 아래 구조를 옮겨 담습니다.**

| 항목 | 변경 |
|---|---|
| 레이어 루트 | `.alert` → **`.alert.ccpane`** (좌측 정렬 · padding 16px) |
| 헤더 | **`.cchead`** 신설 — `.ttl` **「제휴카드 선택」** + `button.ccx`(44px 닫기 · `aria-label="제휴카드 선택 닫기"`) |
| 리드 | `.cclead`를 **`.body` 밖**으로 이동 (스크롤과 분리) |
| 카드 행 | `.ccbody` 안에 **`.ccnmrow`**(`.ccnm` + **`.ccsel`「선택됨」**) 래퍼 추가 |
| CTA | 「확인」 → **「선택 완료」** |

- **Sticky 2행은 유지되지만 구성이 달라졌습니다** — 「요금제명 + 부가세포함 금액」 1행 + 「제휴카드 진입 버튼」 1행. ③에서 01 F 영역 명세 · 05 `C-51` · `C-52` 정의 · 06 `TC-U-45` · `TC-U-46`을 함께 고쳐야 합니다.

- 시나리오 시뮬레이터가 **11건**으로 늘었습니다(조건 6 + 정상 2 + 예외 3). 06 테스트 케이스와 대응시킬 때 참고합니다.
