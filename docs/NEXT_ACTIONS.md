## 1. 수행 기록 시트의 테스트 케이스 번호 갱신 ★★

테스트 케이스에 **4장 「레이어 · 팝업」**(`TC-L-01 ~ 17`)을 신설하면서 흩어져 있던 케이스를 이관하고
**번호를 폐지**했습니다. 외부 수행 기록 시트(A~I열)도 같은 매핑으로 갱신해야 합니다 —
**수행 기록(J~M열)은 덮어쓰지 않습니다.**

| 폐지된 번호 | 이관 후 |
|---|---|
| `TC-F-26` · `TC-F-27` | `TC-L-01` · `TC-L-02` (진입 안내) |
| `TC-E-06` | `TC-L-03` (경로 전환 시점) + `TC-E-06` 재정의(EX-03 판정) |
| `TC-E-07` · `TC-E-08` | `TC-L-05` · `TC-L-04` |
| `TC-F-29` | `TC-L-07`(동의) · `TC-L-08`(동의 안함 · 닫기 · Esc) |
| `TC-F-31` | `TC-L-06` (약정 팝업 구성) |
| `TC-F-30` | `TC-L-11` · `TC-L-14` · `TC-L-15` (시트 3종) + `TC-L-12` · `TC-L-13` · `TC-L-17` |
| `TC-U-44` | `TC-L-10` (속도 제어 안내) |

신설(이관 아님) — `TC-L-09`(약정 재노출 억제) · `TC-L-16`(레이어 키보드 · 포커스).

> **이 부채가 다시 생기지 않게** `RULES.md` 6절에 **코드 번호 불변** 규칙을 넣었습니다 —
