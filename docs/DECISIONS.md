그중 **C-52 · C-60 · C-61 · C-62** 4건은 **S-02 범위 밖**입니다 — 제휴카드 일체를 **가입신청서 작성 내용 확인(마지막 단계)**으로 이관했으므로, 05 개선안의 **「바」 그룹**으로 분리해 관리합니다. 01 화면설계 · 06 테스트 케이스의 적용 대상이 아닙니다.

각 C-nn의 **상세 정의는 `index.html` 내부**에 있으며, **전문 사본은 `docs/REQUIREMENTS.md` 3절**에 있습니다.

### O-18 — 카드 정보 밀도 (이월)
E 영역. 카드 높이 약 300px로 첫 화면에 1~2개만 보입니다. 비교·판단이 목적인 화면인데 동시 비교가 어려워 비교 시트 의존도가 높아집니다.
스펙 면 · 혜택 면 압축으로 240px대까지 줄이면 2개 노출이 가능하나 **정보량 축소 범위가 미정**입니다.

- 프로토타입 실측 카드 높이 — **혜택 없음 298px / 혜택 있음 353px**
- 담당: 기획 · 디자인
- **2026-08-14 이월** — 화면설계는 목업 단계 기준 유지, 압축 범위는 **디자인 시안 단계에서 검토**
- **2026-08-19 부분 완화** — 제휴카드 이관(C-62)으로 하단 고정 영역이 **226.8 → 123.4px**로 줄어 목록이 그만큼 넓어졌습니다. 다만 카드 자체가 **323.7px**(2026-08-19 스케일 정리 후 실측 · 종전 325.8px)여서 **394×704 프레임에서 2개 동시 노출은 여전히 불가**합니다(필요 높이 약 240px). **394×904에서는 2개 임계를 넘겼습니다.** 카드 압축 없이 「2개 노출」을 요건으로 걸 수 없다는 점은 그대로입니다
