## 3. 검증 원칙
**요소 단위 스크린샷만 믿지 않습니다.**
과거 페이지 전면 오버레이 사고를 요소 스크린샷으로 놓쳤습니다. **페이지 전체 스크린샷**을 함께 확인합니다.

새 변경이 있으면 **이전 PASS 결과를 자동 승계하지 않습니다.**

## 4. 06 테스트 케이스 탭과의 관계
`rt-tc` 탭의 **106건**은 **설계 대상 화면(S-02)의 기능 검증**입니다.
이 문서의 매트릭스는 **리포트 문서 자체의 렌더링 검증**입니다. 둘은 별개이며 둘 다 수행합니다.

| | 대상 | 수행 시점 |
|---|---|---|
| 이 문서 18조합 | `index.html` 렌더링 | 문서 수정 직후 |
| 06 탭 106건 | S-02 화면 동작 | 프로토타입 확인 76건 / 나머지는 개발 착수 후 |

06 탭 케이스의 **정의는 `index.html`**, **수행 기록은 외부 시트**가 담당합니다. 명세가 바뀌면 탭을 먼저 고치고 시트 A~I열을 갱신하며, 수행 기록(J~M열)은 덮어쓰지 않습니다.
