## 모바일 / PC 전제

| | 모바일 | PC |
|---|---|---|
| 프레임 폭 | 394px | 700px |
| 콘텐츠 폭 | 360px | 644px |
| 목록 | 1열 | 2열 |
| 비교 시트 | 하단 시트 | 520px 중앙 모달 (C-47) |

**PC는 전체 페이지가 아니라 오버레이 위 중앙 풀 팝업**입니다.
원 서비스는 1000px 캔버스에 `zoom:0.7`로 700px 표시하므로, 설계서는 **실렌더 값(700 / 644 / 2열)**을 기준값으로 씁니다.
PC 2열 격자는 개통 방법 선택 화면(S-01) 격자를 재사용합니다.

**PC 상태 배치 규칙** — PC 상태는 각 영역의 마지막 상태 블록에 두고, 모바일과 차이가 있는 영역(A·B·D·E·F·G)에만 둡니다. 차이가 없는 C.TAB은 모바일 명세에 "PC도 동일"로 표기합니다.
